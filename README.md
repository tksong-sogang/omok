# 오목 (Omok)

브라우저에서 바로 즐기는 오목 게임입니다. 설치나 빌드 없이 실행됩니다.

**▶ 플레이하기: https://tksong-sogang.github.io/omok/**

## 게임 모드
- **사람 대 사람** — 한 화면에서 번갈아 둡니다.
- **사람 대 AI** — AI 레벨을 1~5 중에서 고릅니다. 사람은 항상 흑(선공)입니다.

| 레벨 | AI 방식 |
|---|---|
| 1 | 거의 무작위로 둠 |
| 2 | 공격 위주로 두지만 상위 후보 중 무작위 선택 |
| 3 | 공격과 방어를 따져 한 수 앞을 봄 |
| 4 | 두 수 앞까지 탐색 |
| 5 | 여섯 수 앞까지 탐색 (한 수당 최대 1.5초) |

## 규칙
- 15×15 판, 자유룰
- 가로·세로·대각선으로 **5개 이상** 이으면 승리 (6목 이상도 승리, 금수 없음)
- 판이 가득 차면 무승부

## 로컬에서 실행
저장소를 받은 뒤 `index.html`을 브라우저로 열면 됩니다.

```bash
git clone https://github.com/tksong-sogang/omok.git
```

## 테스트
Node.js 18 이상이 필요하며, 별도 패키지 설치는 없습니다.

```bash
node --test tests
```

## 구조
| 파일 | 역할 |
|---|---|
| `js/game.js` | 보드, 착수, 승리 판정 |
| `js/ai.js` | AI 레벨 1~5 |
| `js/main.js` | 화면 그리기, 클릭 처리, 턴 진행 |
| `tests/` | 규칙·AI 테스트 (`node:test`) |
